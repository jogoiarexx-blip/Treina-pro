# TreinaPro v2.0 — REV5

Esta revisão melhora a clareza das demonstrações 2D sem voltar ao 3D. As mudanças principais são:

- As ilustrações agora mostram **1 • prepare** e **2 • mova assim**.
- Os modos animado, devagar e pausado ganharam **seta principal** e uma **explicação visual curta**.
- Exercícios mais confusos passam a abrir por padrão em **Posições**, para a pessoa entender a sequência antes da animação.
- O modal ganhou um painel **Como entender este desenho** para explicar o que realmente se move.

Todos os 29 exercícios, treinos, histórico, modo offline e PWA foram preservados.
